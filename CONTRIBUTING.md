# Contributing

- Do not commit Apple's/HP's driver package or extracted proprietary binaries.
- Include macOS version, CPU architecture, printer model, and exact reproduction steps.
- Redact USB serial numbers and personal information from logs.
- Keep changes narrow and explain system-file modifications.
- Run `bash -n install.sh uninstall.sh` and ShellCheck before submitting a pull request.
- Do not claim support for combinations that have not been tested.
